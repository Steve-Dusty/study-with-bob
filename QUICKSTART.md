# ⚡ Study With Bob - 30 Second Quickstart

## No API Keys Needed! 🎉

This version uses mock data - works instantly without any setup!

---

## 🚀 Run It

```bash
# 1. Install frontend
npm install

# 2. Install backend
cd backend
pip install -r requirements.txt

# 3. Start backend (in terminal 1)
python main.py

# 4. Start frontend (in terminal 2 - from root directory)
npm run dev
```

## ✅ You're Done!

Open http://localhost:3000

- **Student Dashboard:** http://localhost:3000/student
- **Teacher Dashboard:** http://localhost:3000/teacher
- **API Docs:** http://localhost:8000/docs

---

## 🎮 Try It Out

1. Go to student dashboard
2. Draw on canvas (mouse/touch)
3. Click "Submit Answer"
4. Get instant AI feedback!

---

## 🤔 How Does It Work?

- **No Gemini/OpenAI/Claude** - Uses mock LLM responses
- **No Supabase** - Uses in-memory database
- **No Setup** - Just install & run!

All the AI logic is there, just with hardcoded responses instead of real API calls.
